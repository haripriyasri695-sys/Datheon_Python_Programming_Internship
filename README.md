Project: Hangman Game

Description

Hangman is a simple terminal-based word guessing game developed using Python. The player must guess the secret word one letter at a time.

Features

- Random word selection
- Six incorrect attempts allowed
- ASCII gallows display
- Tracks guessed letters
- Prevents duplicate guesses from reducing attempts
- Displays win or game-over messages

Technologies Used

- Python
- Random module

How to Run

1. Install Python.
2. Open a terminal in the project folder.
3. Run the following command:

python hangman.py
